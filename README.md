# Frameload Shop

Ce repo contient le code de la plateforme e-commerce responsive réalisée avec HTML5, CSS3 et JavaScript vanilla pour le cours HTML débutant.

## Objectif

L'objectif est de développer une plateforme web e-commerce responsive destinée à
servir de projet de référence pour le parcours HTML5 / CSS3 & Intégration Web de
Frameload Learn.

## Fonctionnalités

- Découvrir les produits disponibles
- Consulter les produits
- Rechercher un produit
- Filtrer les produits
- Fiche détaillée d'un produit
- Ajouter un produit au panier
- Modifier les quantités
- Consulter le montant du panier
- Simuler une commande
- Espace client simple

## Installation

```bash
Pour suivre le cours, vous aurez besoin d'installer le code en local sur votre machine. Pour cela :
Ouvrir VS Code ou tout autre éditeur de code
Ouvrir le Terminal
Faites un git clone https://github.com/fdoudou/frameload-shop.git
Faites cd frameload-shop
Commencez à coder!
```

## Utilisation

Une fois index.html ouvert dans le navigateur, vous allez avoir plusieurs pages dans lesquelles il est possible de naviguer :

- **Accueil**
- **Produits**
- **Catégories**
- **Panier**
- **Commandes**
- **Compte**
- **Connexion**
- **Inscription**
- **Tableau de bord admin**
- **Page de gestion des categories**
- **Page de gestion des commandes**
- **Page de gestion des produits**
